# Bundled anatomy asset

`dbcls_human_anatomy_organs.svg` is the **Human anatomy organs** illustration
by the DataBase Center for Life Science (DBCLS).

- Source: https://commons.wikimedia.org/wiki/File:202403_human_anatomy_organs.svg
- License: CC BY 4.0
- License URL: https://creativecommons.org/licenses/by/4.0/

Spatial Target Atlas bundles the SVG so generated reports do not depend on
runtime access to Wikimedia. The anatomy is used as an orientation layer;
expression evidence is rendered separately by Spatial Target Atlas.
